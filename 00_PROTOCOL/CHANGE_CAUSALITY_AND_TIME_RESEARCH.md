# CHANGE, CAUSALITY AND TIME

Project: PROJECT GODFELLA
Experiment: GENESIS ZERO

Status: OPEN RESEARCH — NO MODEL APPROVED
Execution: NOT STARTED

## 1. Research objective

Investigate the relationship between change,
causal order, temporal order and physical time.

The objective is not to establish that time
is fundamental or emergent.

Both possibilities remain open.

## 2. Conceptual distinctions

### Change

A difference between states or properties
of a system.

Change does not, by itself, establish
a complete physical theory of time.

### Order

A relation that establishes precedence
or ordering between elements or events.

An ordering relation does not necessarily
provide a measure of duration.

### Physical time

A physical quantity or structure used
to describe temporal relations and,
depending on the theory, durations.

No particular physical interpretation
of time is approved.

### Causality

A relation describing whether one event
can influence or contribute to another.

Causal relations and temporal measurements
must not be treated as interchangeable.

## 3. Theoretical approaches

### 3.1 Fundamental time

Time is treated as a basic structure
independent of changes in physical systems.

Associated conceptual reference:
Newtonian absolute time.

Status:
THEORETICAL FRAMEWORK — NOT SELECTED.

### 3.2 Relational time

Temporal descriptions are constructed
from relations and correlations between
physical systems or events.

Some approaches to relational quantum
dynamics investigate how temporal
descriptions can be recovered from
correlations between subsystems.

Status:
THEORETICAL FRAMEWORK — NOT SELECTED.

### 3.3 Emergent spacetime

Some theoretical approaches investigate
whether spacetime can emerge from a more
fundamental structure.

Causal set theory is one example.

It represents fundamental structure
using elements and a partial order.

Its relation to continuum spacetime
is investigated through appropriate
continuum approximations.

Status:
THEORETICAL FRAMEWORK — NOT SELECTED.

## 4. Important distinctions

A relation of precedence does not
automatically establish a duration.

A computational execution step does not
automatically represent physical time.

A causal relation does not automatically
provide a complete spatial geometry.

A mathematical ordering does not prove
that physical reality is discrete.

An emergent-time hypothesis is not
an experimentally established fact.

## 5. Open questions for GENESIS ZERO

- Can change be represented without
  assuming a physical clock?
- Can ordering exist without a duration?
- What would establish a causal relation?
- Must causal relations be directional?
- Can a state remain unchanged?
- How would an observer distinguish
  no change from unobservable change?
- Could temporal properties emerge from
  relations between states?
- What assumptions would be introduced
  by a computational sequence?

in a particular form before investigating it.

creates time.
